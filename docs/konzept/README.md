# Projektkonzept

Prüfungsleistung, Umfang ca. 7 Seiten (ohne UI-Mock). Empfohlen: LaTeX + BibTeX.

## Gliederung

- Deckblatt (Thema, Autoren, Kurs, Semester)
1. Projektbeschreibung / Kontext (Vision des Endprodukts)
2. Motivation (Mehrwert für den Anwender)
3. Umfang des MVP (MVP vs. Nicht-MVP)
4. Zielgruppe (inkl. Konsequenzen für UI/UX)
5. Anwendungsfälle + Akteure (inkl. Use-Case-Diagramm)
6. Architektur / Technologiestack (Komponenten, Evaluation, Entscheidung)
7. UI-Mock (Hauptanwendungsfall muss durchlaufbar sein)
- Quellenverzeichnis (auch für Bilder, Tabellen, Diagramme)
