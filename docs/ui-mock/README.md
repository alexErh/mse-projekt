# SkinSentry UI-Mock

In diesem Ordner befinden sich die UI-Mockups für **SkinSentry**.

Die Mockups zeigen die wichtigsten Screens der App und den zentralen Ablauf:

**Home → Körperstelle auswählen → Eignungsprüfung → Foto aufnehmen → Screening → Ergebnis → Verlauf**

Zusätzlich werden die Navigation, die 2D-Körperübersicht, gespeicherte Hautstellen sowie optionale Funktionen wie UV-Index und Arztsuche dargestellt.

## Umfang

Die Mockups dienen dazu, das geplante UI und den wichtigsten Anwendungsfall zu veranschaulichen. Sie sind kein vollständiges Abbild der späteren Implementierung.

Einige Randfälle aus den Use Cases sind deshalb nicht als eigene Screens dargestellt, zum Beispiel:

- **UC-03:** verweigerte Kameraberechtigung
- **UC-04:** alle Fehlerfälle bei unzureichender Bildqualität
- **UC-10:** vollständige Konfiguration aller Erinnerungsintervalle
- **UC-11:** Android-Systembenachrichtigung

Diese Fälle sind in den Use Cases beschrieben. Im UI-Mock liegt der Fokus auf dem normalen Ablauf und den wichtigsten Zuständen.

## Gestaltung

Bei der Gestaltung wurde auf gute Lesbarkeit, ausreichend große Bedienelemente und eine einfache Navigation geachtet.

Als Orientierung wurden folgende Größen verwendet:

- Hauptüberschriften: ca. **24–28 px**
- Abschnittsüberschriften: ca. **18–20 px**
- Fließtext: ca. **16 px**
- kleinere Zusatztexte: mindestens **14 px**
- Button-Text: ca. **16 px**
- primäre Buttons: ca. **48–56 px** Höhe
- Touch-Flächen für Icons: mindestens ca. **44 × 44 px**

Risikostufen werden nicht nur durch Farben, sondern zusätzlich durch Text und Handlungsempfehlungen dargestellt.
